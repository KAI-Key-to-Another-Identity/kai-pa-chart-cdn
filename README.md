# kai-pa-chart-cdn

Public HTTPS PNGs for kai PushPlus research signals (no live trading).

## URL pattern

- raw: `https://raw.githubusercontent.com/KAI-Key-to-Another-Identity/kai-pa-chart-cdn/main/charts/asof-YYYY-MM-DD/<code>.png`
- jsDelivr: `https://cdn.jsdelivr.net/gh/KAI-Key-to-Another-Identity/kai-pa-chart-cdn@main/charts/asof-YYYY-MM-DD/<code>.png`

Prefer jsDelivr for PushPlus HTML img src (stable CDN cache).
